ONE RELEASE PER NAMESPACE: every object name is fixed. The node name is the release name
({{ .Release.Name }}) unless node.name is set.

This chart does not create the Namespace. It must exist and carry the Pod Security labels,
or the node reports `degraded: psa_unenforced`:
  kubectl label namespace {{ .Release.Namespace }} \
    pod-security.kubernetes.io/enforce=restricted pod-security.kubernetes.io/enforce-version=latest \
    pod-security.kubernetes.io/audit=restricted pod-security.kubernetes.io/warn=restricted
